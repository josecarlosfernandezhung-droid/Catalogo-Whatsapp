🌐 Sitio web del catálogo

Conecta tu catálogo con tu sitio web (el HTML que subiste a Netlify/Cloudflare) para que se actualice solo, con fotos incluidas, cada vez que guardas cambios aquí. Necesitas dos cuentas gratis, una sola vez:
1. Firebase (console.firebase.google.com) → crea un proyecto, activa "Realtime Database" y "Authentication → Email/contraseña", crea un usuario con ese método. Copia la API key (Configuración del proyecto) y la URL de la base de datos.
2. imgbb.com → API → copia tu API key.
Esto solo afecta lo que se sube al sitio web. La foto guardada dentro de la app (para tarjetas y PDF) no se toca.
